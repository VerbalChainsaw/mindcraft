  pair. `G: fail`: generic site translation can still put the whole pair on
  one side and the model has no landmark bounds.
- **V2 — reject and retry:** reject a close pair and ask the model again.
  `G: fail`: it detects one bad shape without giving the compiler grounded
  geometry, so repeated local designs remain physically ambiguous.
- **V3 — typed layout plus grounded site transform:** recognize explicit
  `one on each side` and `facing inward`, persist a bounded immutable layout

  landmark's bounded horizontal footprint, and generate two safe cardinal
  axis candidates outside the requested clearance. Require native route proof
  to a legal stance for each fixture, then persist the transformed ordinary
  blueprint. `G: pass`.
- **V4 — semantic DSL expansion:** add landmark references, reserved regions,
  and relational operators to the public design language. `G: pass`, but it
  broadens model command authority and parsing far beyond the observed pair.
