# Campaign 73 — Existing access repair

Player-visible outcome: repair a dangerous gap at an existing doorway with the supplied full block, prove the ordinary route works, return to the requester, and wait.

Hard gates:

- Bind the already-loaded doorway and exact missing surface cells; never choose a fresh construction site.
- Preserve the existing door and building. Do not acquire or place an invented fixture.
- Persist only bounded normalized data and retain Agenda/JobDirector cancellation and restart ownership.
- Delegate block placement to the existing Builder and movement proof to native Pathfinder.
- Natural language and an explicit command must share the same access-repair selector/order compiler.

Frozen weights: semantic fidelity 25, world safety 20, truthful verification 20, reuse of existing mechanics 15, durability/cancellation 10, implementation/blast radius 10.

| Variant | Gate | Score | Decision |
|---|---:|---:|---|
| Prompt-only instructions on generic construction | OUT | — | Cannot bind exact existing geometry; the failed baseline already invented a new door and site. |
| Typed `repair_access` Agenda job with exact loaded-world constraint, ordinary Builder order, then native route visit | IN | 96/100 | Winner: smallest shared seam with exact intent, durable work, existing mechanics, and physical route proof. |
| Extend model-compiled construction with a repair layout constraint and transform its blueprint | IN | 78/100 | Retains an unnecessary model/compiler failure surface for geometry that is already fully observable. |
| Custom placement/movement loop | OUT | — | Violates package-first mechanics and creates parallel execution. |

Decision: implement the typed `repair_access` seam. Selection records the existing lower door, facing, exact bounded gap cells, inside verification stance, outside supported stance, dimension, and requested material. JobDirector compiles those cells into an ordinary Builder work order. Agenda then visits the inside stance through native Pathfinder before returning to the requester and applying terminal Hold.

IN: exact access selection, bounded persistence, ordinary Builder placement, native route proof, focused contract tests, two unchanged Paper replays within Campaign 73.

OUT: generic terrain repair, arbitrary path beautification, new placement mechanics, Pathfinder changes, base redesign, silent-failure narration, unrelated construction cleanup.
