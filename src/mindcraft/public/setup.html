Live Readiness

  1. Select a profile, then confirm its model provider is reachable. Save the matching cloud key only when that profile needs one.
  2. Set the Minecraft host, port, authentication mode, and supported version for the target server.
  3. For a local single-player world, open a world to LAN and use the announced port. For a dedicated server, ensure its host and port accept TCP connections.
  4. Save Launch Config, restart the launcher, then use the dashboard health banner for the exact remaining blocker.

Changes are written to launcher-config.json. Use Restart Launcher to apply them immediately.
